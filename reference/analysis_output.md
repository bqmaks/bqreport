# Construct normalized output from a custom engine

Construct normalized output from a custom engine

## Usage

``` r
analysis_output(
  model = NULL,
  estimates = NULL,
  tests = NULL,
  contrasts = NULL,
  diagnostics = NULL,
  issues = NULL
)
```

## Arguments

- model:

  Optional fitted model.

- estimates, tests, contrasts, diagnostics, issues:

  Optional tidy components.

## Value

An `analysis_output` object.
