# Access analysis result components

Access analysis result components

## Usage

``` r
estimates(x)

tests(x)

diagnostics(x)

issues(x)

attempts(x)

models(x)

descriptives(x)

survival_estimates(x)

omnibus_effects(x)

correlations(x)
```

## Arguments

- x:

  An `analysis_result`.

## Value

The requested tidy result component, or a named list for `models()`.
